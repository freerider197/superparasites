# Typhoon firmware WAVs

Flash by audio: hold FREEZE while powering on, play the WAV into the LEFT input.
Afterwards, re-patch the module's audio input.

| File | What |
|---|---|
| `typhoon-granular-mod-v4-microcell.wav` | Latest: rhythmic DENSITY (/8../2, x1, x2..x8, no audio-rate grains), SIZE = gate, POSITION = clock-aligned slices. |
| `typhoon-granular-mod-v4-supercell.wav` | Same, Supercell variant (use if CV inputs act inverted). |
| `typhoon-granular-mod-v1-microcell.wav` | v1 baseline: click-free windows, clock-locked density, finer diffusion. |
| `typhoon-granular-mod-v1-supercell.wav` | Same, Supercell variant. |
| `ORIGINAL-superparasites-v1.0-microcell.wav` | Official SuperParasites v1.0, unmodified (restore). |
| `ORIGINAL-superparasites-v1.0-supercell.wav` | Official SuperParasites v1.0, unmodified (restore). |

Originals are from https://github.com/patrickdowling/superparasites/releases/tag/v1.0
