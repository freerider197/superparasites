# Typhoon firmware WAVs

Flash by audio: hold FREEZE while powering on, play the WAV into the LEFT input.

| File | What |
|---|---|
| `typhoon-granular-mod-microcell.wav` | Modified granular mode (mode 1). Try this first. |
| `typhoon-granular-mod-supercell.wav` | Same, Supercell variant (use if CV inputs act inverted). |
| `ORIGINAL-superparasites-v1.0-microcell.wav` | Official SuperParasites v1.0, unmodified (restore). |
| `ORIGINAL-superparasites-v1.0-supercell.wav` | Official SuperParasites v1.0, unmodified (restore). |

Originals are from https://github.com/patrickdowling/superparasites/releases/tag/v1.0
